# GACETA — Sitio Web Oficial

## Contexto del Proyecto

Sitio web oficial del sello discográfico GACETA ([@esgaceta](https://instagram.com/esgaceta)). El objetivo es que sea una **experiencia**, no solo una página. Está en producción hace 2 meses, aprobada por el sello. El foco ahora es **pulirla y llevarla al siguiente nivel** sin cambiar la identidad visual establecida.

## Stack Técnico

- **Framework**: React
- **Estilos**: Tailwind CSS
- **Scroll suave**: Lenis
- **Animaciones**: GSAP (con ScrollTrigger)
- **Reproductor**: Nativo, aleatorio

## Estructura de Páginas

- `/` — Home con múltiples secciones
- `/galeria` — Fotos
- `/nosotros` — About con múltiples secciones

## Identidad Visual de GACETA

- **Paleta**: Blanco y negro como base. Uso estratégico del color (morado/violeta, rojos) solo para momentos de impacto
- **Tipografía**: Bold, condensada, de impacto. Estilo editorial urbano. Letras grandes, jerarquía fuerte
- **Estética**: Urban editorial. Sello independiente que juega en grande. Energía de música urbana argentina
- **Fotografía**: Alto contraste, blanco y negro, momentos en vivo, cultura
- **Logo**: Ícono triangular + wordmark "GACETA" / "⊳ GACETA"
- **Tono**: Directo, confiado, cultural. No genérico, no decorativo

## Reglas de Diseño (NO romper)

- Nunca usar gradientes genéricos o colores pasteles
- No cambiar la paleta base establecida
- Mantener la jerarquía tipográfica bold/condensada
- Las animaciones deben sentirse intencionales, no decorativas
- Mobile-first en todas las decisiones

## Áreas de Mejora (foco actual)

1. **Performance**: Velocidad de carga, optimización de assets, lazy loading
2. **Animaciones**: Pulir y elevar las transiciones GSAP + Lenis existentes
3. **UI/UX**: Refinamiento visual sin romper la identidad
4. **Tipografía**: Afinar jerarquía y ritmo visual

## Workflow

Antes de tocar cualquier área:
1. Leer el skill correspondiente
2. Auditar el código existente en esa área
3. Proponer cambios puntuales con justificación
4. Implementar de forma incremental, sin romper lo que funciona

## Lo que NO hacer

- No reescribir componentes enteros sin razón
- No cambiar la identidad visual establecida
- No agregar dependencias sin justificarlo
- No romper el reproductor de música
- No hacer cambios que requieran aprobación del sello sin avisar
